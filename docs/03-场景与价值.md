# 03 · 场景与价值

## 谁在用

月上新频繁、标题 SEO 靠抄的一人店

## 三个典型场景

### 场景 A：关键词挖掘与标题组合
- **触发**：人工
- **之前**：人工从头做一遍，每次口径不一、结果不可比
- **之后**：类目词→平台搜索逻辑→多平台标题
- **收益**：月省文案 10h≈¥300

### 场景 B：五点卖点生成
- **触发**：人工
- **之后**：商品资料→卖点→分平台版本
- **收益**：与①同场景触发，零额外流程

### 场景 C：极限词/广告法合规扫描
- **触发**：事件（文案定稿）
- **之后**：文案→违禁词库→修改建议
- **收益**：一次违规处罚即超全年订阅费

## 价值构成

| 维度 | 说明 |
|---|---|
| 省时间 | 月省文案工时 15h≈¥450 |
| 提一致性 | 同一能力固化成技能，口径不再因人而异 |
| 降风险 | 业务红线写死在提示词里，越界即停 |
| 可审计 | 每个数字可回指输入，产出可追溯 |
